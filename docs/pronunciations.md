# Pronunciations

Text-to-speech often mispronounces names and invented words. Pronunciation lines swap a whole word for a respelling just before narration, for example `Hermione` to `Her-my-oh-nee`.

## Lists and per-book lines

- A **list** is a named set of lines, managed under **Pronunciations**. One list can be marked **automatic** and is then used for every new book.
- When you add a book you pick a list (or none). The list is **copied** into the book, so editing the list later does not change books that already have it.
- A book can also have its **own lines**. Where both cover a word, the book's own line wins.
- "Update from list" refreshes a book's copy from the named list.

## Hearing a respelling

Next to each line is a **Hear** button that plays the respelling in a narrator you choose. It narrates only a few words, and the result is kept so hearing it again is free. Use it to get a respelling right before narrating a chapter.

## Narrated chapters are protected

Chapters that are already narrated are pinned to the lines they were narrated with. Editing lines, or updating from the list, never makes paid-for audio unready.

To hear an edit in a chapter that is already narrated, re-read it: see [Re-reading chapters](rereading.md). Editing lines is refused while a narration job is running.

## Matching

Only whole words are replaced. With no lines at all the text is untouched, so cache keys stay the same as before pronunciation lists existed.
